Conbox Server Setup:

This is my Server setup with samba,avahi and Cosmos cloud

Install:
Install Cosmos Cloud with avahi:
```bash
curl -fsSL https://cosmos-cloud.io/get.sh | sudo -E bash -s
```
Install Samba under Debian,Ubuntu:
```bash
sudo apt install Samba
```
Copy me smb.conf or write you on smb.conf
That for the right 
```bash
sudo mkdir -p /nas
sudo chown -R you_user:you_user /nas
```
